Spatial Video Rendering

Projected video (360°, 180°, wide-FOV) in WebKit's media controls.

Before you start

Enable Spatial Video Rendering in Feature Flags — it is off by default — then reload.

Declared projection

A 360° clip with no projection metadata, so only projection can make it a sphere. On auto it plays flat.

Camera

Absolute: each writes defaultYaw, defaultPitch or defaultFieldOfView. Pressing one twice does nothing the second time.

Relative to the current view, via video.defaultYaw = video.yaw - 90. Drag first, then press one.
