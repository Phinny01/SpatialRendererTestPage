Spatial Video Rendering

Test page for projected video (360°, 180°, wide-FOV) rendered in WebKit's media controls.

Before you start

  1. Open Develop › Feature Flags (Safari Technology Preview).
  2. Enable Spatial Video Rendering. It is off by default.
  3. Reload this page.

Declared projection

A 360° clip that carries no projection metadata at all, so x-webkit-projection is the only thing that can make it render as a sphere. Leave the value on auto and it plays flat.

Camera

Each button assigns to video.defaultYaw, video.defaultPitch or video.defaultFieldOfView, which writes the matching x-webkit- attribute and re-frames the view.

Directly on the video: drag to look around and scroll to zoom (a smaller field of view is more zoomed in). Those move the camera without touching the attributes, so the two sets diverge: yaw, pitch and fieldOfView read back where the camera actually is, while the default ones keep whatever was last assigned. After a write the live value lags one frame, since it only changes once the renderer has drawn. All six are numbers, not strings.
